# Lumen local updates

For local Mac updates use `desktop/scripts/update-mac.mjs`; do not create ad hoc
full app copies or timestamped frontend backups. Follow the install and
`--confirm-working` procedure in `docs/DESKTOP.md`. Confirm only after the new
app launches and Studio and Notes work. Retain one recent working app backup.
Never delete or overwrite the operator's notes, media, station data or existing
station-data recovery snapshot to clean build output. Do not commit runtime
data, credentials, downloaded sermons, installers or app backups.
